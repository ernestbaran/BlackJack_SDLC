
# CardPlay Online - Blackjack

Questo progetto è un gioco di Blackjack giocabile dal browser.

## Funzionalità attuali

- Mazzo gestito tramite API esterna (Deck of Cards).
- Puntata in Dobloni tramite chip.
- Azioni di gioco: Pesca (Hit), Stai (Stand), Raddoppia (Double), Split.
- Gestione degli assi (1 o 11) e del punteggio.
- **Assicurazione quando il banco mostra un Asso, con pagamento 2:1 se ha Blackjack.**
- Statistiche salvate in locale (mani, vittorie, sconfitte, ecc.).
- Interfaccia grafica con HTML, CSS e JavaScript.

## Tecnologie

- HTML5  
- CSS3  
- JavaScript vanilla  

## Come avviare

Aprire `index.html` con un browser moderno (Chrome, Edge, Firefox).
